# 大气圈与天气、气候 - 交互式教学模块

这是一个基于Web的交互式地理教学模块，用于可视化展示大气圈与天气、气候的核心概念。

## 功能模块

### 1. 大气垂直分层

- 可视化展示对流层、平流层、高层大气
- 显示各层的高度范围、温度变化特征
- 动画展示对流运动、飞机飞行、电离层等特征

### 2. 大气受热过程

- 展示太阳辐射（短波）和地面辐射（长波）
- 演示大气对太阳辐射的削弱作用
- 展示大气逆辐射的保温作用
- 支持阴天/晴天模式对比

### 3. 大气运动

- **热力环流**：展示基本的大气环流原理
- **海陆风**：演示白天海风和夜晚陆风
- **山谷风**：展示谷风和山风的形成
- **风的受力分析**：展示水平气压梯度力、地转偏向力、摩擦力的作用

### 4. 全球性大气环流

- **三圈环流**：展示低纬、中纬、高纬环流
- **气压带风带**：演示气压带风带的季节移动
- **季风环流**：展示东亚季风和南亚季风

### 5. 天气系统

- **冷锋**：展示冷锋过境过程
- **暖锋**：展示暖锋过境过程
- **准静止锋**：展示梅雨、贵阳冬雨等
- **气旋**：展示低压系统（如台风）
- **反气旋**：展示高压系统（如伏旱、寒潮）
- **锋面气旋**：展示锋面与气旋的结合

### 6. 气候类型

- 展示9种主要气候类型：
  - 热带雨林气候
  - 热带草原气候
  - 热带沙漠气候
  - 热带季风气候
  - 亚热带季风气候
  - 地中海气候
  - 温带季风气候
  - 温带海洋性气候
  - 温带大陆性气候
- 每种气候类型包含：
  - 分布区域
  - 形成原因
  - 气候特征
  - 气温和降水柱状图
  - 气候类型判读方法

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 点击顶部导航栏切换不同模块
3. 使用各模块内的控制按钮：
   - 播放/暂停动画
   - 调整参数（时间、季节等）
   - 切换不同的子类型

## 技术特点

- **纯前端实现**：无需服务器，可直接在浏览器中运行
- **Canvas绘图**：使用HTML5 Canvas进行2D可视化
- **3D可视化**：使用Three.js实现3D效果，支持2D/3D视图切换
- **交互式设计**：支持动画、参数调整等交互
- **教学导向**：每个模块都配有详细的说明文字

## 3D可视化功能

项目现已支持3D可视化效果，使用Three.js库实现：

- **大气垂直分层**：3D地球模型展示大气层结构
- **全球性大气环流**：3D地球视图展示气压带和风场
- **天气系统**：3D可视化展示气旋、反气旋和锋面系统

每个支持3D的模块都提供"切换到3D视图"按钮，可以在2D和3D视图之间自由切换。3D视图支持鼠标拖拽旋转和滚轮缩放。
