# 太阳系模拟器 - 新功能提案清单

## 📅 天文事件类

### 1. 日食和月食系统 ⭐⭐⭐ ✅

- [x] **日食检测**
  - 检测月球遮挡太阳（从地球视角）
  - 日全食、日偏食、日环食三种类型
  - 实时阴影效果（太阳变暗、地球出现阴影）
  - 事件通知："日食正在发生！"
  
- [x] **月食检测**
  - 检测地球遮挡太阳光照射月球
  - 月全食、月偏食
  - 月球变暗效果
  - 事件通知："月食正在发生！"

- [ ] **食相可视化**（待增强）
  - 显示食相路径
  - 显示食相持续时间
  - 可跳转到下一次食相

### 2. 行星凌日事件 ⭐⭐ ✅

- [x] **水星/金星凌日**
  - 检测水星或金星从太阳前方经过
  - 在太阳表面显示小黑点
  - 事件通知："水星/金星凌日"
  - 显示凌日路径和持续时间

### 3. 行星逆行现象 ⭐⭐ ✅

- [x] **逆行检测**
  - 检测行星相对于背景恒星的逆行运动
  - 视觉标记（行星闪烁或改变颜色）
  - 显示逆行周期
  - 教育性说明："火星正在逆行"

### 4. 流星雨事件 ⭐⭐⭐ ✅

- [x] **流星雨系统**
  - 基于真实流星雨（英仙座、双子座、狮子座、象限仪座）
  - 根据模拟时间自动触发大量流星
  - 流星雨模式（增加流星密度和生成频率）
  - 从辐射点方向生成流星
  - 事件通知："英仙座流星雨高峰期！"
  - 可配置流星密度和持续时间

### 5. 大合相事件 ⭐⭐ ✅

- [x] **多行星大合相**
  - 检测3颗以上行星接近对齐
  - 特殊视觉效果（金色连线）
  - 事件通知："罕见的大合相！"
  - 显示合相角度和持续时间

### 6. 小行星接近事件 ⭐ ✅

- [x] **近地小行星**
  - 随机生成小行星接近地球
  - 显示轨道和距离
  - 危险等级标记（绿色/黄色/红色）
  - 事件通知："小行星接近中"
